HunarLens submission report

The full report is docs/project_report.md. The concise report is
docs/report_short.md, and docs/report_figures.md indexes its supporting figures.
DATA_SOURCES.md lists the data sources and reuse status.

To run the dashboard, install the pinned runtime requirements and run:
    streamlit run app/streamlit_app.py

Raw survey data and individual-level files are excluded. Consult README.md for
setup, data acquisition, tests, and the frozen-model hash.
